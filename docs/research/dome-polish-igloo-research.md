## Reference Signals

- Igloo Inc uses a single frozen object-world as the main memory anchor: a dark stage, cold material depth, scroll-linked object transitions, and sparse UI.
- The Awwwards case study describes browser-native iteration, real-time intro motion, chromatic aberration, frost transitions, and procedural ice-block generation as core production ideas.
- WebGPU.com describes the Igloo execution as WebGL-led, with procedurally grown ice crystals, shader-driven UI text, custom volume data, and a muted blue-grey palette.
- Refs.Gallery frames the language as matte-black void, iridescent ice, hard-nosed optimization, and clear copy hierarchy.

## Translation For Teerth

- The dome should be one memorable polar artifact, not a flat set piece.
- Use procedural geometry instead of downloaded textures: rib count, panel rows, frost shards, rings, and topology seams are deterministic and Vercel-safe.
- Make the object technically personal: S2 core, topology seam network, polar observatory shell, and source-evidence axis.
- Keep the seal untouched in this pass because the user is supplying a seal solution soon.

## Security / Asset Validation Rubric

- [x] No proprietary Igloo geometry, screenshots, textures, scripts, or source assets copied.

- [x] Dome materials are procedural and generated locally from Three.js primitives.
