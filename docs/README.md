# Documentation

Every document lives in one topic directory. Dated records (`design`, `research`) describe a decision or a finding at the time it was made; the other topics describe the tree as it is.

| Topic | What is in it |
|---|---|
| [`architecture/`](architecture/overview.md) | How the app is built: [overview](architecture/overview.md) (loading path, render modes, measured first-load numbers), the [anime engine](architecture/anime-engine.md), the [fx kit](architecture/fx-kit.md) |
| [`testing/`](testing/gates.md) | The Node checks and the load gate, with the commands that produce each number |
| [`backgrounds/`](backgrounds/overview.md) | How a background is chosen and built, and the plan for baked plates |
| [`shaders/`](shaders/README.md) | The shader tool catalogue, generated by `scripts/shader-catalog.mjs` |
| [`site/`](site/seo.md) | What the public site presents: [SEO](site/seo.md), [photography](site/photography.md) |
| [`design/`](design/2026-11-20-route-heat-chunking-design.md) | Dated specs and plans, written before the work: route-heat chunking, cutscene grandify, director epic, graphic 100 |
| [`research/`](research/2026-11-20-route-heat-chunking.md) | Dated records of what was read and measured, and the notes behind the anime renderer |
| [`thesis/`](thesis/topological-rendering.md) | The topological rendering thesis, pinned to the commit that holds its evidence |

Experiments with their pre-registrations and results are in [`../experiments/`](../experiments/README.md); machine-checked statements are in [`../lean/`](../lean/README.md).
