# Backgrounds: the shader table by need

Generated by `node lib/anime/tools/bg-picks.mjs` from catalog.json: only tools rated real that compile. Reach any of them with `await bg.shader(pull)` (kit/bg/index.js), which loads the pack and returns its GLSL, or by hand with `loadPack(pack)` + `glslFor([pull])`. The kit's own painters (sky, facade, stone, ground, water, wood, cards) are the first choice; these are the rest of the table, filed so a builder finds a Shinkai dawn or a flagstone floor without searching 2,004 entries.
