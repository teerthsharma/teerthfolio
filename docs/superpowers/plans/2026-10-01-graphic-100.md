# Graphic 100 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make five control stills, then every remaining place still, pass the igloo object-world gate so the graphic grade moves 67 → 100. After that, first-arrival 2D punch-line pops take the product to 1000.

**Architecture:** Do not restyle the HUD and call it done. Change what the camera looks at, what the materials do under the existing `LIGHT` rig, then the rig itself. Each band ships a still that a HUD-off screenshot can name. `palette.js` stays the one material language; `places.js` grows an optional `look` aim so docks stop staring at empty snow.

**Tech Stack:** Next.js 16, R3F, three r178, existing `scripts/shot.mjs`, `npm run check`.

**Spec:** The graphic grade on `local/grade` (canvas `teerthfolio-grade.canvas.tsx`). Control stills: spawn, `pr-mujoco-3396`, `pr-triton-kernels-22`, `pr-tensorflow-124410`, `pr-pyrefly-4180`. Bruno cute stays. Plastic stills do not.

## Global Constraints

- Camera azimuth stays fixed (up the screen is always −z). No orbit-on-stick.
- Show, never tell: no new diagrams, charts, or 3D captions. PR numbers already on MujoRush necks stay.
- Words and numbers still come from `data/showcase.json`. This plan does not rewrite claims.
- `npm run check` stays green after every band. If a dock moves, the dry-dock / path / district rules must still pass.
- After any `LIGHT` change, re-solve `C` so snow sun/shade stay near L239 / L193 (see `palette.js` header). Predicted vs captured pixels within 4 levels on a 1440×900 Chrome shot.
- Shot command is always real Chrome, never Playwright's bundled Chromium: `node scripts/shot.mjs --url "http://localhost:3000/?play&spawn=<id>&hud=off" --out verification/graphic/<id>.png --w 1440 --h 900`.
- Do not add a docs framework, CI, or a new package.

## Review Focus

- A visitor who never moves still has to see a place, not a lettering plate.
- `?play` stills used for this grade must not include the giant W coach.
- Ice, metal, snow, water must split by roughness/value, not only hue. Triton vertex colours stay; roughness and spec change.
- Dam dock still must contain the crest and wet reservoir. Moving the dock must not put it in water (`waterGap > MOTION.sealRadius`).
- Reduced motion still skips the jump-in and must not inherit a broken follow aim.
