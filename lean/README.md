# Lean

Machine-checked statements behind the thesis in [`../docs/thesis/topological-rendering.md`](../docs/thesis/topological-rendering.md), section 7, and behind the invariants and propositions of [`../docs/topological-shader/README.md`](../docs/topological-shader/README.md). Core Lean 4.36.0, no Mathlib. Check one file from `lean/` with `lake env lean TopologicalRendering/<File>.lean` (plain `lean <file>` also works for every file except `Governor.lean`, which imports `Flip`); `lake build` checks all of them. A file passes when it exits 0 with no `sorry`, `admit`, `axiom` or `native_decide`. The exit codes and axiom lists below are from a re-run of each file on Lean 4.36.0 (`#print axioms` at the end of every file).

The statements are integer models of the real-valued statements in the thesis. Flip uses integer samples and thresholds with the gap as `(hi - lo).toNat` and states the bound without division. Components works with reachability itself, so that a map on components is well defined because walks map to walks, over `Nat -> Int` fields on an arbitrary relation. Heat replaces the decay factor by a rational `a / b`, measures heat in integer units of `1 / b`, and takes the per-update deposit bound `K` as given.

Governor writes the shifted latch as `Flip.step` at `lo + u`, `hi + u` (Flip's orientation: on at `x >= hi`) and reduces it to Flip on the sample list minus the shift list; the lists may differ in length and the shorter one decides. Shrink uses the D7 orientation (LIVE below `tau_lo + u`, not LIVE above `tau_hi + u`, hold between) with the sample and shift as functions `Nat -> Int`, index 0 being the initial state. Lemma T counts a cyclic run as an index `i` with `bit i` set and `bit (i - 1)` clear, so the all-ones mask has no start and is excluded, as the statement excludes it; `Simple m` is one run of ones and one run of zeros, and this is the combinatorial content of the local lemma, not the PL Morse reading, which stays a sketch. MinLipschitz takes non-empty lists (`x :: xs`). NormalisedStep divides by nothing: dividing by `M * M'` gives the thesis form `|Hn' - Hn| <= 2K / M`.
